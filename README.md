# BizAI Frontend Project

## 📌 Project Overview
BizAI is a responsive frontend project developed using HTML, Tailwind CSS, and CSS. It includes multiple pages for a simple business management system.

## 📄 Pages
- Login
- Home (Index)
- Dashboard
- Customers
- Products

## 🛠 Technologies Used
- HTML5
- Tailwind CSS
- CSS3

## ✨ Features
- Responsive design
- Navigation bar
- Login page
- Dashboard with statistics
- Customer management page
- Product management page
